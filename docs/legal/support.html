What you need before you start

Sijil IT is a client for Odoo. It has no database of its own, so it needs a server you already run:

  • Odoo 17, 18 or 19, reachable over HTTPS
  • The Maintenance app installed — this is what holds the assets. Adding Employees unlocks assignment and the staff directory; Inventory adds a second asset source.
  • A user account with read access to those models. The app never works around an Odoo permission — if your account cannot see something, neither can the app.

Signing in

  1. Enter your server address, for example https://company.odoo.com.
  2. Tap Detect databases. The app asks the server which databases it hosts and fills in the name for you.
  3. Tap Test connection to confirm the server answers and to see which Odoo apps it has.
  4. Continue, then sign in with your Odoo username and password — or, better, an API key.

To create an API key in Odoo: Preferences → Account Security → New API Key. An API key can be revoked without changing your password.

Common problems

"This server keeps its database list private"

Not an error. Most production instances switch off database listing on purpose. Type the database name into the Database field by hand — your Odoo administrator can confirm the exact name, and it is case-sensitive.

"Database not found"

The name is almost right but not exact. Database names are case-sensitive, and a hosted Odoo database is often named after the subdomain rather than the company.

Sign-in is refused although the password is correct

Check that you are on the right toggle — Password versus API key. An API key entered as a password will be rejected, and the other way round. If your Odoo enforces two-factor authentication, you must use an API key.

A screen or a button is missing

That is deliberate. The app checks which Odoo apps you have and hides what it cannot support rather than showing something broken. If the maintenance screens are missing, the Maintenance app is not installed; if assignment is missing, it is Employees.

The scanner says camera access is off

Open iOS Settings → Sijil IT → Camera and turn it back on, or use the button on that screen, which takes you straight there. You can always search for an asset instead of scanning it.

Changes are not appearing in Odoo

You were probably offline when you made them. Open Sync to see exactly what is still queued and why. Nothing is lost — the queue survives closing the app, and empties when the connection returns.

Reporting a bug

Open Settings → Diagnostics, which holds a recent record of what went wrong with passwords and keys already stripped out. Send us that, along with:

  • What you were doing when it happened
  • Your Odoo version, and the app version from Settings → About
  • Your device and iOS or Android version

Please do not send passwords or API keys. We never need them.

Privacy

Your data goes to your own Odoo server and never to us. Details in the privacy policy.

ما تحتاجه قبل البدء

«سجل IT» تطبيق يتصل بـ Odoo، وليست له قاعدة بيانات خاصة به، لذا يحتاج خادمًا يعمل لديك بالفعل:

  • Odoo 17 أو 18 أو 19، متاح عبر HTTPS
  • تطبيق الصيانة (Maintenance) مثبّتًا — فهو الذي يحمل الأصول. وإضافة الموظفين (Employees) تفتح الإسناد ودليل الموظفين، والمخزون (Inventory) يضيف مصدرًا ثانيًا للأصول.
  • حساب له صلاحية الاطلاع على هذه النماذج. التطبيق لا يتجاوز صلاحيات Odoo إطلاقًا — فما لا يراه حسابك لا يراه التطبيق.

تسجيل الدخول

  1. أدخل عنوان الخادم، مثل https://company.odoo.com.
  2. اضغط اكتشاف قواعد البيانات، ليسأل التطبيق الخادم عن قواعد البيانات لديه ويملأ الاسم نيابة عنك.
  3. اضغط اختبار الاتصال للتأكد من استجابة الخادم ومعرفة تطبيقات Odoo المثبّتة عليه.
  4. تابِع، ثم سجّل الدخول باسم المستخدم وكلمة المرور — أو بمفتاح API وهو الأفضل.

لإنشاء مفتاح API في Odoo: التفضيلات ← أمان الحساب ← مفتاح API جديد. ويمكن إلغاء المفتاح دون تغيير كلمة المرور.

مشكلات شائعة

«هذا الخادم يُبقي قائمة قواعد بياناته خاصة»

ليست مشكلة. أغلب الخوادم الإنتاجية تعطّل عرض القائمة عن قصد. اكتب اسم قاعدة البيانات يدويًا — يؤكده لك مسؤول Odoo لديك، وهو حسّاس لحالة الأحرف.

«قاعدة البيانات غير موجودة»

الاسم قريب لكنه غير مطابق. الأسماء حسّاسة لحالة الأحرف، وغالبًا ما تُسمّى قاعدة البيانات المستضافة باسم النطاق الفرعي لا باسم الشركة.

يُرفض الدخول رغم صحة كلمة المرور

تأكد من المفتاح الصحيح: كلمة مرور أم مفتاح API. فإدخال مفتاح API مكان كلمة المرور يُرفض والعكس كذلك. وإن كان Odoo لديك يفرض التحقق بخطوتين، فمفتاح API إلزامي.

شاشة أو زر غير ظاهر

هذا مقصود. يفحص التطبيق تطبيقات Odoo المتاحة ويخفي ما لا يستطيع دعمه بدل أن يعرض شيئًا معطّلًا. فغياب شاشات الصيانة يعني أن تطبيق الصيانة غير مثبّت، وغياب الإسناد يعني الموظفين.

الماسح يقول إن إذن الكاميرا مغلق

افتح الإعدادات ← سجل IT ← الكاميرا وفعّله، أو استخدم الزر في تلك الشاشة الذي ينقلك إليها مباشرة. ويمكنك دائمًا البحث عن الأصل بدل مسحه.

التغييرات لا تظهر في Odoo

غالبًا كنت دون اتصال وقت إجرائها. افتح المزامنة لترى ما لا يزال في الانتظار وسببه. لا شيء يضيع — فقائمة الانتظار تبقى بعد إغلاق التطبيق وتُفرَّغ عند عودة الاتصال.

الإبلاغ عن خلل

افتح الإعدادات ← التشخيص، وفيه سجل حديث لما حدث بعد إزالة كلمات المرور والمفاتيح منه. أرسله لنا مع:

  • ما كنت تفعله وقت حدوث المشكلة
  • إصدار Odoo، وإصدار التطبيق من الإعدادات ← حول
  • طراز جهازك وإصدار نظامه

من فضلك لا ترسل كلمات مرور أو مفاتيح API. نحن لا نحتاجها أبدًا.
